# App Folder

## Purpose

This folder contains the Streamlit demonstration interface. It lets users enter Urdu tweets, preview leakage-aware preprocessing, run inference with an available packaged model, inspect confidence scores, review the saved leaderboard, and read a rule-based explanation of the result.

## Contents

| File/Folder | Description |
|---|---|
| [streamlit_app.py](streamlit_app.py) | Streamlit dashboard application file |

## How It Is Used

The Streamlit application loads trained model checkpoints from the output directories and provides an interactive web UI.
- It uses inference utilities from [../src/inference.py](../src/inference.py) to preprocess text and query predictions.
- It uses [../src/explanation_assistant.py](../src/explanation_assistant.py) to provide transparent template-based explanations. These are not generated by an external language model and are not causal model explanations.
- It reads the overall model leaderboard from [../outputs/results/model_comparison_leaderboard.csv](../outputs/results/model_comparison_leaderboard.csv) to display a model performance comparison table.

To run the Streamlit application:
```powershell
streamlit run app\streamlit_app.py
```

## Notes

- The three packaged classical models are runnable. Transformer inference is supported only when complete local weight files are restored; otherwise the app falls back to `baseline_linear_svm.joblib`. Neural inference is represented by saved results rather than a packaged checkpoint path.
- The application file should be edited manually to add UI features or modify visualization states.
