# Error Analysis Folder

## Purpose

This folder contains qualitative and quantitative error analysis outputs. These artifacts isolate specific failure modes of the models (such as minority class confusion, negation, sarcasm, and high-confidence misclassifications) to support model debugging and explanation.

## Contents

Key error analysis artifacts include:

| File/Folder | Description |
|---|---|
| [baseline_error_summary.json](baseline_error_summary.json) | High-level summary of error statistics and metrics |
| [explanation_samples.json](explanation_samples.json) | Curated examples of predictions with generative analysis explanations |
| [baseline_linear_svm_test_high_confidence_wrong.csv](baseline_linear_svm_test_high_confidence_wrong.csv) | Test examples where SVM predicted the wrong label with high confidence |
| [baseline_linear_svm_test_minority_class_errors.csv](baseline_linear_svm_test_minority_class_errors.csv) | Test classification errors involving the minority classes (Neutral) |
| [baseline_linear_svm_test_confusion_pairs.csv](baseline_linear_svm_test_confusion_pairs.csv) | Frequencies of specific label confusion pairings |

## How It Is Used

The files in this directory are generated by running error analysis:
- **Generation**: Created by `src/error_analysis.py` and `src/analyze_baseline_errors.py` based on prediction outputs.
- **Reporting**: These findings are summarized in `docs/results_analysis.md` and explored in `notebooks/05_error_analysis.ipynb`.
- **Explanations**: [explanation_samples.json](explanation_samples.json) contains deterministic, template-based interpretation examples. They summarize observable text and error patterns rather than claiming causal explanations.
