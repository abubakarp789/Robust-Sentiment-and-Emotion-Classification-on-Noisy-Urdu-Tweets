# Predictions Folder

## Purpose

This folder contains CSV files holding true and predicted labels generated by the trained models on the validation and test splits. Storing these prediction tables allows for decoupling training and downstream analysis.

## Contents

This folder contains predictions for each of the 7 evaluated models on both the validation and test partitions. Key representative files include:

| File/Folder | Description |
|---|---|
| [baseline_linear_svm_test_predictions.csv](baseline_linear_svm_test_predictions.csv) | Test predictions from final selected Linear SVM model |
| [baseline_linear_svm_validation_predictions.csv](baseline_linear_svm_validation_predictions.csv) | Validation predictions from final selected Linear SVM model |
| [transformer_xlm_roberta_test_predictions.csv](transformer_xlm_roberta_test_predictions.csv) | Test predictions from XLM-RoBERTa model |

## How It Is Used

Each prediction CSV contains the following fields:
- `id`: Tweet ID
- `text`: Original Urdu tweet text
- `clean_text`: Cleaned text used as model input
- `true_label`: Ground truth sentiment label (`Positive`, `Negative`, or `Neutral`)
- `predicted_label`: Label predicted by the model
- `confidence`: Class probability or decision function score
- `correct`: Boolean flag indicating if the prediction matches the true label
- `split`: Partition name (`validation` or `test`)
- `model_name`: Label identifier of the model

These tables are used by:
1. `src/evaluate.py` to compile metrics stored in [../results/](../results/).
2. `src/error_analysis.py` to identify failure modes (sarcasm, negation, etc.) and isolate misclassified samples.
