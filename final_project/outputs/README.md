# Outputs Folder

## Purpose

This folder contains saved experimental and submission artifacts: available model files, predictions, metrics, figures, error analysis, the final-report evidence snapshot, and the report copy.

## Contents

| File/Folder | Description |
|---|---|
| [models/](models/) | Saved model checkpoints and mappings |
| [predictions/](predictions/) | True vs predicted output files for validation and test splits |
| [results/](results/) | Metrics, leaderboards, training history, and reports |
| [error_analysis/](error_analysis/) | Error-type summaries and explanation samples |
| [figures/](figures/) | Plots and heatmaps for reports and the interactive app |
| [report_snapshot/](report_snapshot/) | Dual-task Assignment 4 result tables and figures |
| [reports/](reports/) | Final research-paper PDF |

## How It Is Used

The subfolders in this directory store files produced by the pipeline scripts in [../src/](../src/):
1. **Models**: Classical pipelines and available deep-model support files are stored in [models/](models/); missing deep weights are documented there.
2. **Predictions**: Generated by the model-training workflows and saved in [predictions/](predictions/).
3. **Leaderboard and Metrics**: Consolidated by `src/compare_models.py` into [results/](results/).
4. **Error Data**: Produced by error analysis scripts and saved in [error_analysis/](error_analysis/).
5. **Plots**: Created by plotting scripts and exported to [figures/](figures/).
6. **Report Evidence**: The report snapshot and PDF preserve the research-paper results separately from the packaged sentiment rerun.
