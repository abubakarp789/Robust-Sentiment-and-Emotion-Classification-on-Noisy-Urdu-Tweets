# Processed Data Folder

## Purpose

This folder stores the intermediate processed dataset. It holds the cleaned and label-normalized Urdu tweets before they are partitioned into train/validation/test splits.

## Contents

| File/Folder | Description |
|---|---|
| [processed_sentiment_dataset.csv](processed_sentiment_dataset.csv) | Full preprocessed and label-normalized dataset |

## How It Is Used

The processed dataset is generated programmatically by running [../../src/create_splits.py](../../src/create_splits.py).
- **Expected Rows**: `517,966`
- **Columns**:
  - `id`: Unique identifier for each tweet
  - `raw_text`: Original tweet text (retained for audit and analysis)
  - `clean_text`: Normalized, noise-cleaned, emoji-stripped tweet text
  - `raw_label`: Noisy original emotion/sentiment label from Twitter
  - `normalized_label`: Cleaned and consolidated canonical emotion label
  - `task_label`: Final mapped target sentiment label (`Positive`, `Negative`, or `Neutral`)
  - `text_length`: Number of characters in the cleaned text

After this file is created, [../../src/create_splits.py](../../src/create_splits.py) splits it into the train, validation, and test datasets saved in [../splits/](../splits/).
