# Submission Reports

## Purpose

This folder contains the final academic and technical documentation files for the Urdu Tweet Sentiment and Emotion Classification semester project. It includes the final report, dataset details, ethics statements, presentation slides, checklists, and scripts.

## Contents

| File/Folder | Description |
|---|---|
| [final_report.md](final_report.md) | Comprehensive final technical report covering the entire project pipeline |
| [dataset_card.md](dataset_card.md) | Standardized dataset card detailing properties of SentiUrdu-1M |
| [ethics_and_limitations.md](ethics_and_limitations.md) | Ethics analysis, potential risks, and limitations of this study |
| [final_evaluation_summary.md](final_evaluation_summary.md) | Final metric compilation and evaluation callouts |
| [slides_outline.md](slides_outline.md) | Structured slide-by-slide outline for the project presentation |
| [demo_script.md](demo_script.md) | Step-by-step narration script for the live system demonstration |
| [export_instructions.md](export_instructions.md) | Documentation on how to package and export the project for submission |
| [final_submission_checklist.md](final_submission_checklist.md) | Checklist validating completion of all project milestones |

## How It Is Used

The markdown files in this directory are the primary deliverables for course evaluation.
- They synthesize data from `outputs/results/` and `outputs/error_analysis/` to present a unified scientific analysis.
- The outline in [slides_outline.md](slides_outline.md) and demonstration guide in [demo_script.md](demo_script.md) are used to organize the final presentation.
- All files in this folder are intended to be read and maintained manually.
